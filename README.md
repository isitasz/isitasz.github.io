# isitasz.github.io

Portfólio da Isabella Camillo (violet gothic edition).

## Publicar no GitHub Pages

1. Crie um repositório público chamado `isitasz.github.io` na sua conta.
2. Envie estes arquivos:
   ```bash
   git init
   git add .
   git commit -m "feat: portfolio"
   git branch -M main
   git remote add origin https://github.com/isitasz/isitasz.github.io.git
   git push -u origin main
   ```
3. Em Settings > Pages, escolha `Deploy from a branch`, branch `main`, pasta `/ (root)`.
4. Em alguns minutos o site fica em https://isitasz.github.io

## Arquivos

- `index.html`: o site inteiro (HTML, CSS e JS), sem build.
- `isabella-camillo-cv.pdf`: o currículo. O botão do site já tem uma cópia embutida.
